# 🍯 熊熊大富翁 · Bear Monopoly

蜜熊岛上的熊熊们用「蜂蜜金」铸成熊熊币，每年举办大富翁大赛，争夺年度熊熊首富的金蜂蜜王冠。
一款可爱熊主题的大富翁桌游（网页版）。支持人机对战，规则围绕「买地 → 升级 → 收过路费 → 逼对手破产」的淘汰制循环展开。

## 🎮 在线试玩

https://t-ctrl-web.github.io/bear-monopoly/
打开即玩，无需安装。手机 / 平板 / 电脑浏览器均可（需要 WebGL 支持）。

## 📖 玩法

- 5 位角色（蜜团团 / 雪球球 / 团子 / 瞌睡噜 / 月芽儿），各带被动特性，同时决定 AI 性格
- 32 格 3D 低模棋盘，五大区域：蜂蜜广场 / 蜂蜜花田 / 渔夫湾 / 竹笋竹林 / 蘑菇密林
- 买地 → 三级升级 → 收过路费（垄断 ×2）→ 逼对手破产
- 18 张事件卡（幸运蜂巢）、糖罐陷阱、破产清算（变卖 → 借款 → 淘汰 → 产业移交）

## 🗂 项目结构

```
.
├── index.html                 # 游戏页面（入口）
├── game.js                    # 全部游戏逻辑 + Three.js 场景
└── lib/three.min.js           # Three.js r149（本地打包，离线可用）
```

## 🛠 本地运行

下载后直接双击 `index.html` 即可（Three.js 已本地化，无需联网）。
若浏览器限制本地脚本，可在目录内启动静态服务器：

```
python3 -m http.server 8000
# 打开 http://localhost:8000
```
